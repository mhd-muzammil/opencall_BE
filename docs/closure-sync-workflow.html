What this page does. Every hour it downloads today's Flex Closure ASP Report from FieldEZ, imports it exactly as the Import Closure Dates button on Closed Calls does, then matches those closures against the calls your team marked Case-Closed on the Open Call Report — and rewrites the Flex Status cell on every row that matches.
